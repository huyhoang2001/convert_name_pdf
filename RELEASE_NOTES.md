# B6H v3.0.6 - Maintenance Release

- Improved Settings storage management with clearer selector navigation, destination validation, and feedback.
- Component artifacts: production-signed Frontend, Core modular update packages and lightweight Windows x64 Setup; the validated Wordcraft runtime was reused when unchanged.
- The Setup is unsigned by Authenticode because B6H is free and open source. Windows may show an unknown-publisher or SmartScreen warning. Verify its published SHA-256 checksum and download only from this official GitHub release.
